09 / 色彩与材质
由场景提取色彩，用语义规范应用

视觉来源 → 设计判断 → 语义角色 → 使用约束。

视觉来源

天空、水面、云朵场景与珠光角色，提取柔紫、粉白和冷蓝的色彩关系。

设计判断

围绕聆听与放空场景，弱化强对比装饰；深紫文字保障信息层级，珠光强调播放主控。

证据边界

参数来自当前网页与历史稿；舒适感是设计目标，尚未通过正式用户测试验证。

语义角色 / 色值
应用与约束
核心文字
text / primary · #36325E

场景标题与正文；浅底承载阅读

辅助信息
text / secondary · #6E678C

说明与导航图标；避免叠在复杂图像上

选中与进度
accent / selected · #9C91D0

与描边、图标共同表达状态，不用于小正文

基础底色
surface / base · #EEE6EE

衔接天空场景，承托内容层

材质高光
material / highlight · #FFFFFF

图标和轮廓；必须落在有明暗层次的控件上

主控材质

145° 渐变 · 2 px 白色轮廓
局部高光与紫色投影统一复用

色彩使用规范

文字、状态与材质分层管理。
选中状态同时使用图标或描边。
透明组件在最终场景中复核可读性。

纯色对比 · 当前色值计算

主要文字 / 底色　9.69 : 1
辅助文字 / 底色　4.32 : 1

辅助小字需加深或置于更浅承载面；
不将上述比值视为整页可访问性认证。
